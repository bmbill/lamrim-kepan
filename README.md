# 師父講解科判

《菩提道次第廣論》日常老和尚（師父）講解的科判整理：依廣論科判找到師父在每一段原文的**消文理路**與**延伸理路**（立、破、因、喻、下手處、回扣原文），附口譯、逐字稿與音檔段落。

- 網頁：開 `index.html`（或 GitHub Pages）。可搜尋原文、科判、音檔時間（例如「69A」「69A 12」），可下載整課或區段的直排科判圖。
- 目前整理：思惟苦諦(1)（先說苦諦之意趣）、思惟苦諦(2)（思惟八苦・生苦）、思惟苦諦(3)（生苦・老病死苦）。
- 每課的資料在 `*_師父科判.json`；`*.png` 是直排科判圖（含消文／只有延伸兩版）。

資料來源：逐字稿與音檔來自[廣論時時聽](https://lamrim.xyz/)；廣論原文頁碼依《菩提道次第廣論》課本。
